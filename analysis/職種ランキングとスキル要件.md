# 住宅・リフォーム業界 求人分析 ── 職種ランキングと求められるスキル

職業訓練カリキュラム開発の根拠資料として、`data/求人票/` の求人票PDF（13ファイル・507頁）を
機械抽出・分類した結果をまとめる。抽出スクリプトは `scripts/extract_jobs.py`、
抽出結果の全件データは `analysis/data/求人一覧.csv`（同内容のJSONも同梱）を参照。

---

## 0. データの出所と前提（先に読むこと）

| 項目 | 内容 |
| --- | --- |
| 出所 | ハローワーク求人票（フルタイム様式）のPDF出力 |
| 対象地域 | 宮崎・山梨・愛媛・鳥取・千葉の5県 |
| 取得時点 | 千葉のみ2026年8月10日、他4県は2026年9月7日 |
| 総頁数 | 507頁（1頁＝1求人） |
| 重複除去後 | 446件（同一事業所・同一職種の重複掲載を除去） |
| うち住宅・リフォーム業界 | **379件 / 178事業所** |

**この資料の限界（カリキュラム設計の判断材料として重要）**

1. **統計調査ではなく、キーワード検索結果のスナップショット。** 「住宅」「リフォーム」で
   ヒットした求人であり、母集団を代表する標本ではない。件数の大小は「その職種の求人が
   世の中に多い」ことではなく「この検索条件でこれだけ拾えた」ことを示す。
2. **「住宅」の語で介護系求人が大量に混入している。** 住宅型有料老人ホーム／サービス付き
   高齢者向け住宅の介護職・看護職・調理職が65件あった。業界が違うのでランキングからは
   除外し、末尾に別掲した。
3. **同一職務の重複計上がある。** 例：タマホームは「正社員／エリア限定社員／地域限定社員」を
   別求人として出しており、1店舗で3件になる。件数だけを見ると営業職が過大評価されるため、
   本資料では**求人件数と事業所数を併記**している。
4. **抽出は座標ベースの機械処理、分類は職種名の規則ベース。** 職種・仕事内容・経験・資格の
   各欄は446件すべてで取得できたが、分類には数件程度の誤りが残りうる（うち2件は
   仕事内容を読んで手動で補正済み）。個別確認はCSVで可能。

## 3. 全職種を横断して共通する要件

1. **普通自動車運転免許はほぼ前提条件。** 業界内379件の92%が「必須」と明記
   （営業98%・施工管理98%・設備工事95%・メンテ100%・建材営業100%）。
   **免許を持たない受講者は、訓練以前にここが参加要件になる。**
2. **Word・Excelの基本操作は職種を問わず求められる。** PCスキル欄に記載のある業界内109件の
   大半が「Word・Excelの基本操作」「文字入力」レベルで、高度なスキルを求める求人はごく少数。
   現場系（施工管理・メンテナンス）では**現場写真の貼付、タブレット入力、日報入力**が具体的に挙がる。
3. **資格は「必須」より「あれば尚可」が圧倒的に多い。** 宅建士・建築士・施工管理技士は
   ほぼ優遇条件であり、入口要件ではない（例外：設計職の建築士、設備工事の第二種電気工事士）。
   → **訓練の主目的を「難関資格の取得」に置くと的を外す。**「未経験可の求人に届く基礎スキル＋
   就職後に取る資格へのブリッジ」という設計のほうが求人実態に合う。
4. **未経験可の求人は業界内の45%（169件）。** ただし職種で大きく偏る（建材営業76%／施工技能職71%
   ／メンテ65% ⇔ 設計21%／施工管理27%／営業33%）。

## 5. 次のステップ（カリキュラム開発に向けた論点）

本資料は「求められる職種と、その仕事内容・スキル」の整理までを扱った。カリキュラム化には
以下の意思決定が必要であり、いずれも未確定である。

1. **訓練の実施地域はどこか。** 千葉（施工管理・技能職が厚い）と地方4県（営業偏重）で
   最適なカリキュラムが異なる。
2. **ターゲット職種を1つに絞るか、複合させるか。** 件数最大は営業。未経験可率と賃金の
   両立で見ると「メンテナンス・アフターサービス」「施工技能職」「設備工事」が入りやすい。
3. **訓練期間をどれくらい取るか。** 3ヶ月・6ヶ月・1年で到達可能な資格が変わる
   （第二種電気工事士は短期で可能、二級建築士は受験資格の制約で不可）。
4. **受講者の前提条件をどう置くか。** 特に普通自動車運転免許の有無が求人の大半を左右する。

これらを決めれば、職種別に「訓練科目 × 時間数 × 到達目標 × 対応する求人要件」の
マトリクスに落とし込める。
